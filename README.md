# ГолосКалендар 3.2.0 — сповіщення про зустрічі

- `HolosCalendar-3.2.0-debug.apk` — інсталятор для Android 8+.
- `HolosCalendar-3.2.0-project.zip` — повний проєкт Android Studio та APK у папці APK.
- `SHA256SUMS.txt` — контрольні суми.

Вихідний commit: [9a22b114c388f05ce006542620fbf6e209a21dea](https://github.com/salenko93-hash/HolosCalendar-Android/tree/9a22b114c388f05ce006542620fbf6e209a21dea).

## Як увімкнути

Відкрийте подію → Нагадування → у час початку, за 5, 10, 15, 30, 60 хвилин або за день → Зберегти в ГолосКалендарі / Оновити подію. Початково нагадування вимкнені, зокрема для зустрічей зі старої версії.

Android 13+: надайте дозвіл на сповіщення. Для точного часу на Android 12+ є окремий дозвіл: Налаштувати сповіщення → Точний час. Без нього можливе запізнення; збереження зустрічі залишається доступним. Якщо відмовили в дозволі, увімкніть його через Налаштувати сповіщення.

Сповіщення відкриває відповідну подію. Перенесення змінює нагадування; вимкнення та видалення прибирають його. Черга відновлюється після перезавантаження й оновлення APK, уже показані нагадування не відтворюються знову. Міграція SQLite зберігає зустрічі 3.1.0. Зміна часового поясу не переносить сам момент зустрічі.

Якщо час нагадування минув, але зустріч ще попереду, воно надійде одразу; старі події понад п’ять хвилин після початку не відтворюються. Звук, вібрація та показ на заблокованому екрані залежать від налаштувань Android. Примусова зупинка застосунку в Android вимикає alarms до повторного запуску. Зовнішній календар налаштовує свої нагадування окремо; синхронізації немає.

## Перевірено

83 JVM-тести та 40 Android-тестів на API 26, без пропусків; lint без зауважень, підпис APK v2 та zipalign. Перевірено реальний показ NotificationManager, доставку через AlarmManager/manifest receiver, відкриття потрібної зустрічі, міграцію SQLite, збереження налаштування нагадування, протидію дублям та застарілим alarms. На API 35 локально не запускалося; для API 26/35 налаштовано CI. У тестах фактичного часу потрібен доступ до точних alarms; без нього такий тест пропускається.

Дозволи Android 12/13+, налаштування Redmi, звук і відновлення після повного перезавантаження телефона додатково перевіряються на пристрої за TESTING.md.

## Установлення

Підпис збігається з хмарною версією 3.1.0, versionCode підвищено до 9: встановлюйте поверх неї. Не видаляйте застосунок для звичайного оновлення — його власні зустрічі зберігаються локально. Для попередньої збірки з іншого ПК потрібен той самий ключ підпису; можна перебудувати ZIP на своєму ПК.

Розпакуйте ZIP і відкрийте папку HolosCalendar в Android Studio з JDK 17. Це debug-збірка.
