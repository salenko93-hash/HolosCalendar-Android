# ГолосКалендар Redmi

Нативний Android-додаток без власного сервера. Українські голосові команди розпізнаються системним сервісом Android (офлайн не гарантовано), дата/час обробляються локально, підтвердження події відбувається у встановленому календарі.

**APK:** Actions → Build HolosCalendar Android APK → Run workflow → Artifacts → HolosCalendar-Redmi-debug-APK.

Це тестова debug-збірка, не реліз для Google Play. Додаток обробляє одну подію за команду.

## Локальна перевірка

Потрібні повний JDK 17, Gradle 8.9, Android SDK Platform 35 та Build Tools 34.0.0.

```sh
gradle --no-daemon assembleDebug lintDebug testDebugUnitTest
```

APK: `app/build/outputs/apk/debug/app-debug.apk`. GitHub Actions виконує ті самі перевірки для main і pull request.

## Введення події

1. Продиктуйте фразу або введіть її й натисніть «Розпізнати подію».
2. Перевірте назву, дату, час і тривалість. Розпізнані значення не є підтвердженням користувача.
3. Натисніть «Продовжити в календарі» та збережіть подію у відкритому календарі.

Приклади: «Завтра о 14:30 Зустріч у Києві», «05.11 о 9 Нарада», «25 жовтня 2027 о 14.30 Зустріч».
Числові дати: `дд.мм`, `дд/мм` з необов'язковим роком. Час: `14:30`, `о 14.30`, `о 9`.
Дата без року означає найближчу майбутню таку дату; 29 лютого — найближчий високосний рік.
«Наступного понеділка» означає на тиждень пізніше найближчого понеділка (включно із сьогодні).
Словесний час («о другій», «о пів на третю»), відносні години, повторення та кілька подій в одній фразі поки не підтримуються — оберіть час вручну.
Інтерфейс підтримує системну темну тему, зміну розміру шрифту та відступи системних панелей.

## Перевірка на телефоні перед поширенням

- Android 8+ та Android 15: клавіатура, системні панелі, світла/темна тема, великий шрифт, TalkBack.
- Голосове введення українською: успіх, скасування, відсутній сервіс; офлайн не гарантовано.
- Поворот екрана: збереження тексту, назви, дати, часу та тривалості.
- Передача в календар: назва, часовий пояс пристрою, початок і вибрана тривалість; скасування не означає збереження.
- Відсутній календар, порожня назва, відсутні дата/час і подія в минулому.
