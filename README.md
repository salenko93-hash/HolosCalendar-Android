# ГолосКалендар Redmi

Нативний Android-додаток без власного сервера. Українські голосові команди розпізнаються системним сервісом Android (офлайн не гарантовано), дата/час обробляються локально, підтвердження події відбувається у встановленому календарі.

**APK:** Actions → Build HolosCalendar Android APK → Run workflow → Artifacts → HolosCalendar-Redmi-debug-APK.

Це тестова debug-збірка, не реліз для Google Play. Додаток обробляє одну подію за команду.
