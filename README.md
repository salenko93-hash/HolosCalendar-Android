## Що додано

Словесний час із частинами доби, пів/чверть години, відмінкові дати й відносні проміжки, розмовна тривалість, часові інтервали, повторення та цілоденні діапазони. Без названої тривалості поле порожнє. «За пів години» — початок через 30 хвилин; «на пів години» — тривалість.

«О сьомій» потребує вибору 07:00/19:00. «Під вечір», «наприкінці місяця», «кілька хвилин» потребують точного поля. «Через день», «двічі на тиждень», «кожного другого вівторка» потребують вибору правила. «В останню неділю місяця» без «щомісяця» — одна дата з підтвердженням; для серії оберіть щомісячне повторення.

Зміна/видалення стосується всієї серії. Час серії зберігається у первісному поясі; неіснуючі дати й весняний час пропускаються. Цілоденна відпустка включає показаний останній день і не отримує вигаданої тривалості. Для її сповіщення оберіть окремий час.

«Нагадай» обирає нагадування у час початку. Збережіть подію локально та надайте дозволи Android: сповіщення на 13+, точний час на 12+. Без точного доступу можливе запізнення. Власний календар і парсер не потребують мережі; голос залежить від системного сервісу uk-UA. Розширення правил тексту не навчає саму модель Google.

## Перевірено

182 JVM-тести (у тому числі 87 фраз), повні 50 Android-тестів на API 26 на фінальному APK. Помилок і пропусків немає; lint без зауважень. Підпис v2 та zipalign перевірено. API 35 налаштований у CI, результат тут не підтверджено. Перевірено також установлення 4.0.0 поверх 3.2.0 зі збереженням події та її нагадування й запуск через попередній ярлик. Google-розпізнавач, звук, налаштування Redmi й зовнішній календар додатково перевіряються на телефоні за TESTING.md.

## Як установити

Установлюйте поверх хмарної 3.2.0: ключ збережено, versionCode підвищено до 10. Міграція SQLite 1/2 → 3 зберігає попередні події й нагадування. Не видаляйте застосунок для звичайного оновлення — локальні події зберігаються тільки на телефоні. Якщо попередній APK підписаний іншим ключем на вашому ПК, перебудуйте новий проєкт тим самим ключем.

Для Android Studio розпакуйте ZIP та відкрийте папку HolosCalendar (JDK 17, SDK 35). Це debug-збірка. Автоматичної синхронізації із зовнішнім календарем і хмарного резервного копіювання немає.
