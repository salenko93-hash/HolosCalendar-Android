# ГолосКалендар 3.0.3 — готова debug-збірка

- `HolosCalendar-3.0.3-debug.apk` — інсталятор для Android 8+.
- `HolosCalendar-3.0.3-project.zip` — повний проєкт для Android Studio; у папці APK всередині також є готовий інсталятор.
- `SHA256SUMS.txt` — контрольні суми завантажень.

Вихідний commit: [54deb1f152831699388a205b382273cf042fd7db](https://github.com/salenko93-hash/HolosCalendar-Android/tree/54deb1f152831699388a205b382273cf042fd7db).
[Звіт про помилки та виправлення](https://github.com/salenko93-hash/HolosCalendar-Android/blob/54deb1f152831699388a205b382273cf042fd7db/REVIEW-3.0.3.md).

Перевірено: 55 JVM-тестів, 9 Android-тестів на API 26, lint без зауважень, підпис APK v2 та zipalign. API 35 тут локально не запускався; для нього налаштовано CI. Справжнє розпізнавання голосу й збереження події перевіряються на телефоні.

## Установлення

Завантажте APK на телефон і відкрийте його. Це debug-підпис хмарної збірки, який може відрізнятися від підпису попереднього APK з вашого ПК. Якщо Android повідомить про несумісний підпис, перебудуйте проєкт на тому самому ПК або видаліть попередню версію й установіть цю. Видалення очищує незбережену форму додатка; збереження календарних подій виконує зовнішній календар.

Для роботи з кодом розпакуйте ZIP і відкрийте папку HolosCalendar в Android Studio з JDK 17.
