# ГолосКалендар 3.0.4 — тривалість лише за вашою вказівкою

- `HolosCalendar-3.0.4-debug.apk` — інсталятор для Android 8+.
- `HolosCalendar-3.0.4-project.zip` — повний проєкт для Android Studio та готовий інсталятор у папці APK.
- `SHA256SUMS.txt` — контрольні суми завантажень.

Вихідний commit: [30e0a8a49b4ba815741b0342b3e47b8a17d499ae](https://github.com/salenko93-hash/HolosCalendar-Android/tree/30e0a8a49b4ba815741b0342b3e47b8a17d499ae).

## Що змінено

Без вказівки тривалості поле показує «Тривалість: не вказано». Приклади: «на 30 хвилин», «на годину», «на півтори години», «на 1 годину 30 хвилин». «Через годину» задає час початку, а не тривалість. Новий розбір без тривалості та очищення форми прибирають попереднє значення. У діалозі тривалість можна вибрати або скинути через «Не вказано».

Без тривалості календар отримує лише початок, без часу завершення. Зовнішній календар може запропонувати власну тривалість у своєму редакторі.

Перевірено: 69 JVM-тестів, 15 Android-тестів на API 26, lint без зауважень, підпис APK v2 та zipalign. Тести перехоплюють фактичний перехід у календар і перевіряють відсутність часу завершення без тривалості та правильний кінець із нею. API 35 локально не запускався; для нього налаштовано CI. Справжнє голосове введення й збереження події перевіряються на телефоні.

## Установлення

Завантажте APK на телефон і відкрийте його. Підпис збігається з хмарною збіркою 3.0.3, тож її можна оновити цим APK. Це debug-збірка; якщо попередню версію зібрано на іншому ПК, підпис може відрізнятися. У такому разі перебудуйте проєкт на тому самому ПК або видаліть попередню версію (незбережена форма очиститься).

Для роботи з кодом розпакуйте ZIP і відкрийте папку HolosCalendar в Android Studio з JDK 17.
