# Структура проєкту

- `MainActivity.java` — прив'язка XML-екрана, ручне редагування, відновлення форми, голосове введення та календарний intent. Дані не вважаються збереженими після відкриття чужого редактора.
- `VoiceParser.java` — незалежний від Android розбір української фрази. Використані фрагменти вилучаються один раз; решта тексту зберігає оригінальне написання. `ZonedDateTime now` передається явно для обліку DST; overload із LocalDateTime інтерпретує значення в UTC для детермінованих локальних тестів. Відносні команди повертають також точний Instant.
- `DurationParser.java` — явні вказівки тривалості, окремі від відносного часу початку. Відсутність тривалості представлена null, без прихованого значення за замовчуванням.
- `CalendarEvent.java` — перевірені дані події, часовий пояс, виявлення неіснуючого/повторюваного часу та тривалість у реальних хвилинах. Для відносної команди зберігається точний Instant, який не можна непомітно перенести на інше входження осіннього часу.
- `res/layout/activity_main.xml` — екран; `res/values*` — тексти, кольори, стилі та темна тема; `res/drawable` — векторні іконки й фони.
- `src/test` — регресійні перевірки парсера та календарної моделі.
- `src/androidTest` — перевірки обробки результату розпізнавання й відновлення Activity на Android; вони виявляють несумісності, яких немає на настільному JDK.
- `gradle/wrapper`, `gradlew`, `gradlew.bat` — однакова версія Gradle для Android Studio, Windows, Linux і CI.

Нативний Java/Android SDK без обов'язкових зовнішніх UI-бібліотек. Стандартна бібліотека `java.time` доступна з minSdk 26. Application ID залишено `ua.holoscalendar.redmi` для сумісності з попереднім проєктом; версія 3.0.4 / versionCode 7. Потрібен той самий підпис для встановлення поверх попереднього APK.

Нові задачі розробки виконуються в наявному checkout; хмарна задача вже ізольована, створювати Git worktree без прямого прохання не потрібно.

Тривалість у CalendarEvent необов’язкова. MainActivity передає EXTRA_EVENT_END_TIME лише за наявності валідної тривалості; інакше зовнішній календар сам визначає поведінку редактора.
