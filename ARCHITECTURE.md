# Структура проєкту

- `MainActivity.java` — прив'язка XML-екрана, ручне редагування, відновлення форми, голосове введення та календарний intent. Дані не вважаються збереженими після відкриття чужого редактора.
- `VoiceParser.java` — незалежний від Android розбір української фрази. Використані фрагменти вилучаються один раз; решта тексту зберігає оригінальне написання. `LocalDateTime now` передається явно для повторюваних тестів.
- `CalendarEvent.java` — перевірені дані події, часовий пояс, виявлення неіснуючого/повторюваного часу та тривалість у реальних хвилинах.
- `res/layout/activity_main.xml` — екран; `res/values*` — тексти, кольори, стилі та темна тема; `res/drawable` — векторні іконки й фони.
- `src/test` — регресійні перевірки парсера та календарної моделі.
- `gradle/wrapper`, `gradlew`, `gradlew.bat` — однакова версія Gradle для Android Studio, Windows, Linux і CI.

Нативний Java/Android SDK без обов'язкових зовнішніх UI-бібліотек. Стандартна бібліотека `java.time` доступна з minSdk 26. Application ID залишено `ua.holoscalendar.redmi` для сумісності з попереднім проєктом; версія 3.0 / versionCode 3. Потрібен той самий підпис для встановлення поверх попереднього APK.

Нові задачі розробки виконуються в наявному checkout; хмарна задача вже ізольована, створювати Git worktree без прямого прохання не потрібно.
